# Data Analyst Portfolio Plan

## 1. Goal
Create a modern, high-contrast, and performant portfolio website hosted on GitHub Pages that highlights analytical capabilities through a literary-inspired narrative.

## 2. Tech Stack
* **Structure:** HTML5
* **Styling:** Vanilla CSS (no framework)
* **Typography:** JetBrains Mono (via Google Fonts)
* **Deployment:** GitHub Pages

## 3. Visual & Design Specifications
* **Theme:** "Dark Mode" aesthetic.
    * *Background:* `#121212` (or similar deep charcoal/black).
    * *Text:* `#E0E0E0` (off-white for readability).
    * *Accents:* `#4CAF50` (terminal green) or `#00E5FF` (cyan) for interactive elements/links.
* **Typography:** JetBrains Mono exclusively, maintaining a "code-editor" feel.
* **Hero Section:** A sophisticated, minimalist layout emphasizing your problem-solving philosophy using titles derived from the previously discussed literature.

## 4. Execution Phases

| Phase | Task | Deliverable |
| :--- | :--- | :--- |
| **I: Initialization** | Create repo, structure project files (`/css`, `/js`, `/assets`). | Base directory structure. |
| **II: Styling** | Implement CSS resets, color variables, and JetBrains Mono setup. | Functional "Dark Mode" layout. |
| **III: Content** | Draft copy for Hero, Projects, and Contact sections. | Static content rendering. |
| **IV: Deployment** | Configure GitHub Pages and finalize remote push. | Live URL. |
